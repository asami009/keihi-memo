# 経費メモ（仮）

使ったお金をその場でメモして、「これ経費？」と迷ったものはあとでまとめて人に聞ける、個人事業主向けの経費のメモ帳です。
スマホのブラウザで開く1枚のページで、**有料のサービスもログインも使っていません。**

---

## できること

| 機能 | 内容 |
|---|---|
| 経費メモ | 払った金額（税込）を入れて、分類をふだんの言葉（「移動」「道具・文房具」「打ち合わせ」など15種類）から選ぶだけ。日付・ひとこと・レシートの写真はなくてもOK |
| 迷ってる | 「これ経費？ 迷ってる」を押すと「迷いリスト」に入ります。何に迷っているかも書けます。分類で「わからない」を選んだときは自動で入ります |
| 迷いリスト | 迷っているものが付箋で並びます。「迷いリストを送る・コピーする」で、LINEやメールに貼れる文になります。答えが出たら「経費に入れる」か「経費から外す」を選びます |
| まとめ | 月ごと・1年（1〜12月）ごとの合計と、分類ごとの金額 |
| 表の書き出し | 月ごと・1年ごとに、Excel・Numbers・Googleスプレッドシートで開ける表（CSV）を保存できます。税理士さんに渡す用 |
| 確定申告まで | ホームに「◯年分の確定申告　しめきりまで あと◯日」を出します |
| 控え | メモと写真をまとめた控えファイルを保存し、別のスマホで「控えから戻す」ができます |

### しないこと

- 経費になるかどうかの判断（AIも使っていません）
- 税金の計算・申告書づくり
- 銀行やカードとの連携、ログイン

### 正直に書いておくこと

- **データ（メモ・写真）は、そのスマホのブラウザの中だけに保存されます。** どこのサーバーにも送られません。そのかわり、機種変更やブラウザのデータ削除で消えます。ときどき「せってい」→「控えを保存する」で控えを取ってください
- iPhoneでは、ブラウザで開いたページと、ホーム画面のアイコンから開いたアプリで、データの保存場所が別になります。**先にホーム画面に追加して、アイコンから開いて使ってください。** ブラウザで入れたメモを移すときは、ブラウザ側で「控えを保存する」→アイコン側で「控えから戻す」
- iPhoneのSafariのまま使うと、7日ほど開かない日が続いたときにデータが消えることがあります（Safariの仕組み）
- LINEでURLを送ると、LINEの中のブラウザで開きます。そこで入れたメモは、Safariやホーム画面のアイコンとは別の場所にたまります。送るURLの最後に `?openExternalBrowser=1` を付けると、いつものブラウザで開きます
- 表に出る「勘定科目（めやす）」は、選んだ分類から機械的に入れた目安です。「道具・文房具」で1件10万円以上のものには「要確認」と添えます。正しい科目は税理士さんと決めてください
- しめきり日は「例年3月15日（申告は2月16日から）・土日なら次の月曜」で計算しています。その年の日付は国税庁のお知らせで確かめてください
- 写真はメモ用の控えです。レシート・領収書の紙はとっておいてください
- 表（CSV）は先頭に文字化けを防ぐ印（BOM）を付けています。会計ソフトにそのまま取り込めるかは確かめていません

## ファイルの中身

```
index.html            画面のもと
style.css             見た目
js/app.js             画面の動き（メモの保存・迷いリスト・まとめ・表の書き出し・控え）
sw.js                 一度開いたら電波がなくても使えるようにする仕組み
manifest.webmanifest  ホーム画面に置いたときの名前とアイコン
icons/                アイコン
robots.txt            検索サイト向けの設定（下の注意を見てください）
```

- 検索サイトに載せない設定は、`index.html` の `<meta name="robots" content="noindex, nofollow">` です。`robots.txt` はサイトの一番上（ドメイン直下）に置いたときしか読まれないので、`アカウント名.github.io/リポジトリ名/` に置く場合は効きません

### アプリの名前が入っている場所（名前を決めたら全部差し替える）

| ファイル | 場所 |
|---|---|
| `index.html` | `<title>`・`apple-mobile-web-app-title`（iPhoneのホーム画面でアイコンの下に出る名前）・`description` |
| `manifest.webmanifest` | `name`・`short_name`（Androidのアイコンの下に出る名前）・`description` |
| `js/app.js` | `APP_NAME`・控えのファイル名（`'経費メモ_控え_'`）・1行目のコメント |
| `style.css` | 1行目のコメント |
| `README.md` | 1行目の見出し |

**`keihi-aikata` という文字は、名前を決めても変えないでください。** メモの保存場所（localStorage のキー・IndexedDB の名前）、控えファイルの `app` 欄、`sw.js` のキャッシュ名に使っていて、変えると入れたメモや控えが読めなくなります。

## 動作確認の方法（パソコンで）

1. このフォルダで「ターミナル」を開き、次を入力して Enter
   ```
   python3 -m http.server 8000
   ```
2. ブラウザで `http://localhost:8000` を開く（index.html をダブルクリックで開くと、一部が動きません）
3. 次を順に試します

| 試すこと | うまくいっていれば |
|---|---|
| 「はじめる」を押す | ホームに「しめきりまで あと◯日」が出る |
| 「＋ 経費をメモする」→ 金額 `1280` → 「打ち合わせ」→「メモする」 | 「メモしました（◯月◯件目）」と出て、さいきん入れたメモに並ぶ |
| メモを押す →「これ経費？ 迷ってる」→ 迷っていることを書いて保存 | ナビの「迷いリスト」に数字が付き、付箋が出る |
| 迷いリストで「答えが出た」→「経費に入れる」 | 付箋が消え、「答えが出たもの」に入る |
| 「まとめ」→「◯月の表を保存」 | `経費一覧_◯年◯月.csv` が保存され、Excelで開くと文字化けしない |
| 「せってい」→「控えを保存する」→「ぜんぶ消す」→「控えから戻す」 | メモが元どおりに戻る |
| ページを再読み込みする | メモが残っている |

## 公開の手順（GitHub Pages・無料）

1. https://github.com でリポジトリを作る（Public）
2. このフォルダの中身（index.html、style.css、js、icons など全部）をアップロード
3. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」
4. 1〜2分待つと `https://（アカウント名）.github.io/（リポジトリ名）/` で開けます
5. iPhoneのSafariでそのURLを開き、共有ボタン →「ホーム画面に追加」

### 直したファイルを公開し直すとき

- `sw.js` の `var VERSION = 'keihi-aikata-v1';` の数字を1つ上げてからアップロードします（上げないと、スマホに古い画面が残ることがあります）
- 公開し直した直後は、古いページが数分出ることがあります。VERSION を上げてあれば、開き直したときに新しい版が届いて1回だけ自動で読み込み直します
